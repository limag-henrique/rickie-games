# Estratégia de testes

Unidade: transições de cada engine, pontuação, empate, votos duplicados, políticas de entrada, timer, serialização. Integração: HTTP, Socket.IO, credencial, snapshot e persistência. E2E: anfitrião, quatro jogadores, tela compartilhada e espectador, incluindo reconexão e proibição de dados privados. Carga: múltiplas salas e conexões concorrentes. Esta entrega executa unidade da engine; integração/E2E e carga entram após o adaptador persistente.
